# 🚗 FP Selection

Projeto de uma página de seleção de carros desenvolvida com **HTML, CSS e JavaScript**.

A proposta é apresentar diferentes modelos de carros através de uma interface visual, com navegação entre os veículos e informações básicas de cada modelo.

Projeto Online: https://victorlopesdeveloper.github.io/car-gallery/

## ✨ Funcionalidades

* Navegação entre diferentes carros
* Exibição da imagem e informações do veículo selecionado
* Controles para avançar e voltar entre os modelos
* Indicador visual da posição atual
* Interface responsiva
* Animações e transições utilizando CSS

## 🛠️ Tecnologias utilizadas

* **HTML5** — estrutura da página
* **CSS3** — estilização, layout, responsividade e animações
* **JavaScript** — navegação e interação entre os carros


## 🎯 Objetivo

Este projeto foi desenvolvido como um exercício prático para aprimorar conhecimentos em **HTML, CSS e JavaScript**, principalmente na criação de interfaces interativas e manipulação de elementos através do JavaScript.


## 📚 Aprendizados

Durante o desenvolvimento deste projeto, foram praticados conceitos como:

* Estruturação de páginas com HTML
* Flexbox e posicionamento com CSS
* Responsividade
* Transições e animações
* Manipulação do DOM
* Eventos de clique com JavaScript
* Alteração dinâmica de conteúdo
